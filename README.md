# 숨은 — 방문객 수로 고르는 가을 1박 2일

HTML/CSS/JavaScript로 만든 정적 사이트입니다. 별도 설치·DB·API 키 없이 실행됩니다.

## 실행

`index.html`을 브라우저로 열거나 압축을 푼 `sumeun` 폴더에서 로컬 서버를 실행합니다.

Windows (Python 설치 시):

    py -m http.server 8000

macOS/Linux:

    python3 -m http.server 8000

http://localhost:8000 으로 접속합니다. 찜한 여행은 브라우저의 localStorage에 저장됩니다.

## 데이터와 선정 기준

- 대표 관광지점의 공식 연간 집계 입장객 1명 이상, 50,000명 미만.
- 2025년 한국문화관광연구원 관광지식정보시스템의 지점별 합계 집계.
- 실제 조회 응답에서 추출한 6개 지점과 조회조건은 `sources/visitor-counts-2025.json`에 보관.
- 공개 관람·산책 또는 일반인 예약이 가능한 장소. 운영 안내 출처를 연결.
- 숙소는 NOL의 5점 만점 이용자 평점 3.0 이상이며 후기 1개 이상인 곳. 호텔 성급과 다름.
- 운영 공지에 있는 중단 시설·통제 등산로는 일정에서 제외.
- 대표 장소의 정기 휴무일과 확인된 고정 휴관일을 출발 날짜로 걸러냄. 명절·공휴일 예외·임시 통제는 운영기관 확인 필요.
- 장소 집계는 지역 전체 관광객·주민 수·실시간 혼잡도를 뜻하지 않음. 연계 장소는 방문객 선정 기준의 적용 대상이 아님.

현재 가을 추천 4개 대표 장소: 지훈문학관, 검마산자연휴양림, 고산창포마을, 구재봉자연휴양림.

2026년 9~11월 출발 코스만 추천합니다. 가을 문학 산책, 가을 운영 중인 소나무 숲, 감·곶감의 수확 문화, 가을 숲 경관의 근거가 있는 곳으로 좁혔습니다. `AUTUMN_SELECTION`에서 계절 선정 근거·출처·추천 기간을 공개하고 `AUTUMN_TRIPS`만 화면과 찜 목록에 사용합니다. 한지마을·구산어촌의 일반 코스는 기존 데이터에 보관하지만 가을 추천에서 제외합니다.

추천 기간은 편집 제안입니다. 단풍 절정 예보나 2026년 수확 체험 운영 확정일이 아닙니다. 소나무는 상록수이므로 검마산을 붉은 단풍 명소로 안내하지 않습니다. 창포마을 감따기 등은 올해 운영·예약 확정 시에만 진행합니다. 과거 계절 소개와 현재 운영 확인을 구분해서 표기합니다.

자료 확인일: 2026-10-13. 숙소별 평점·리뷰 수는 이날 확인한 출처 페이지 표시값입니다. 최신 가격·객실 예약 가능 여부를 조회하지 않습니다.

## 관광 정보 처리

현재는 한국관광공사 공식 관광 페이지, 숲나들e, 지방정부, 마을 운영기관의 공개 자료를 검토해 넣은 고정 데이터입니다. TourAPI 서비스키가 구성되어 있지 않으며 브라우저에서 TourAPI를 호출하지 않습니다. 방문객 통계는 TourAPI 관광지 소개와 별도의 자료입니다.

공식 정보가 없는 후보는 2026년 작성·방문일이 확인되는 후기만 보완 자료로 사용할 방침입니다. 현재 추천하는 4개 장소에는 공식 자료가 있어 블로그만으로 확정한 장소는 없습니다. 공식 개방 상태·입장객 근거·숙소 평점을 충족하지 못한 후보는 추천 데이터에서 제외합니다.

추후 TourAPI 연동 시 서비스키는 서버 환경변수로 관리하세요. TourAPI 장소 정보만으로 낮은 방문객 수나 숙소 이용자 평점을 판정하지 마세요. 리뷰의 적음은 방문객의 적음과 다릅니다.

## 수정할 파일

- `index.html`: 메인 화면, 조건 선택, 기준 설명
- `style.css`: 반응형 디자인
- `data.js`: 장소·통계·출입·숙소·음식·일정·팁·우천·출처 데이터
- `app.js`: 필터, 랜덤 추천, 상세 탭, 저장, 일정 다운로드
- `sources/visitor-counts-2025.json`: 방문객 수의 근거 스냅샷

## 확인

Node.js가 있으면 프로젝트 폴더에서:

    node scripts/verify.cjs

데이터-통계 일치, 숫자·평점·출입 조건, 휴무일, 첫 화면 숨김, 버튼 추천, 4개 가을 코스의 계절 근거·일정·숙소·먹거리·팁, 찜·해제, 다운로드 내용 등을 확인합니다. 이 검증은 DOM 호출을 모의한 코드 검증이며 실제 브라우저 화면·모바일 렌더링 테스트가 아닙니다. 관리형 미리보기는 권한 제한으로 실행되지 않아 화면 QA는 미검증 상태입니다.
